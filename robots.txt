# ⚠️ ليه مفيش Disallow للأدوات الداخلية هنا؟
# ---------------------------------------------------------------
# الأدوات الداخلية (لوحات التشغيل، mart-admin، QuickOrder...) كلها
# فيها <meta name="robots" content="noindex, nofollow"> في الصفحة
# نفسها. ودي أقوى من Disallow هنا، لأن:
#
#   Disallow  = "متزحفش الصفحة دي"
#   noindex   = "متحطهاش في نتائج البحث"
#
# ولو منعنا الزحف بـ Disallow، Google مش هيقدر يفتح الصفحة أصلاً
# عشان يشوف الـ noindex اللي جواها. فلو صفحة منهم كانت اتفهرست
# قبل كده، هتفضل في النتائج للأبد لأننا قافلين عليه الباب اللي
# كان هيعرف منه إننا مش عايزينها.
#
# فالصح: نسيب الزحف مفتوح، والـ noindex جوه كل صفحة هو اللي
# يضمن إنها تختفي من النتائج (وتتشال لو كانت موجودة).
